# 无障碍字幕审校台

这是面向公共文化视频发布团队的字幕质量审校系统。它只保存媒体引用与字幕文本，不接收或存储视频本体。字幕编辑可以建立任务、提交带时间轴的不可变修订、运行确定性质量检查并处置问题；独立审核员完成抽检复核；发布负责人冻结获批版本，生成规范化 WebVTT、冻结清单、SHA-256 摘要和唯一发布凭据。工作台还可重新计算发布包并核验完整审计摘要链。

## 构建与运行

项目需要 Go 1.23 或更高版本。标准构建命令：

```text
go build ./...
```

启动浏览器工作台：

```text
go run ./cmd/server -addr=127.0.0.1:19081
```

然后访问 `http://127.0.0.1:19081/`。监听地址仅允许回环地址；可通过 `-addr=127.0.0.1:<port>` 修改，也可将 `PORT` 设置为端口号，使服务监听 `127.0.0.1:<PORT>`。默认 SQLite 数据库为 `caption-audit.db`，可通过 `-db` 指定其他路径。

## 测试与自检

运行全部测试：

```text
go test ./...
```

执行真实 HTTP 冒烟流程：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck -selfcheck-timeout=15s
```

自检会实际启动回环监听，经同源 JSON API 完成建档、修订、确定性检查、问题处置、独立复核、冻结、下载和验证，然后主动关闭服务。自检使用共享内存 SQLite，不会改写默认业务数据库。

## 业务约束

工作台任务侧栏支持按状态、发布规范、源语言、目标语言和片名或媒体引用筛选，并返回稳定分页及状态统计。修订提交前可执行无副作用预检；质量问题支持原子批量处置、相邻修订差异和抽样建议。冻结前可生成绑定任务版本的放行确认摘要，发布验证会保留可分页的验证历史。

- 所有写操作使用 `expectedVersion` 乐观并发控制和 `idempotencyKey` 幂等记录。
- 修订一经提交不可覆盖；整改通过父修订关系提交继任版本。
- 阻断问题未清零时不能进入独立复核，修订提交者不能审核自己的修订。
- 只有已通过复核的当前修订可由发布负责人冻结，冻结后任务与证据不可修改。
- WebVTT、清单和审计事件采用确定性规范化与 SHA-256 摘要，验证接口会报告可定位的不一致原因。
